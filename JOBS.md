# Job market signals

What hiring teams for Ron's target roles are asking for, and how the portfolio answers them. The `job-scout` agent (`.claude/agents/job-scout.md`) keeps this file current. The `content-writer` agent reads it so copy speaks to real job descriptions.

This file informs emphasis and word choice. It never overrides `CONTENT.md`: the voice, the honesty rules and the "never invent facts" rule still win. A keyword only goes into copy when Ron's real work backs it up.

## Target profile

- **Roles:** Senior UX Designer, Senior Product Designer, Product Designer III (individual contributor).
- **Strongest fit:** consumer products, eCommerce and marketplaces, checkout and fintech, cross-market or international products, AI-assisted design workflows.
- **Location:** San Francisco Bay Area, or US remote.
- **Experience band:** postings asking for about 3–8 years.

Ron can change any of this; the scout searches from it.

## Sources

- **Public job listings** found by web search: company career pages and public boards (Greenhouse, Lever, Ashby, Built In).
- **Posts Ron pastes in**, including LinkedIn posts. The scout cannot read LinkedIn itself: it needs Ron's login, and automated scraping breaks LinkedIn's terms. Ron copies a post's text (and link) into the chat and the scout logs it like any other.
